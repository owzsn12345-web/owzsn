# 셋페스 취향표

이미지로 보내준 취향표를 참고해서 만든 4인용 인터랙티브 웹페이지입니다.

## 사용법
1. `index.html`을 브라우저에서 열기
2. 위 범례에서 원하는 상태를 선택
3. 표의 두 멤버가 만나는 칸을 클릭
4. `전체 초기화`로 모두 지우기
5. `이미지로 저장`으로 현재 결과 저장

## 멤버 변경
`script.js`의 아래 부분만 수정하면 됩니다.

const members = ["오율", "룰", "우진", "루이"];

예:
const members = ["A", "B", "C", "D", "E"];
